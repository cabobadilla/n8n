## Español

Este proyecto de n8n es un asistente conversacional que recomienda libros a través de Telegram usando inteligencia artificial. El flujo interactúa con usuarios para conocer sus intereses literarios y genera un ranking de los mejores libros según las críticas.

### Características principales
- Asistente AI especializado en recomendación de libros.
- Interacción conversacional por Telegram.
- Generación de listas de 10 libros con ranking basado en críticas.
- Respuesta automática y personalizada según los intereses del usuario.

### Herramientas y nodos usados
- OpenAI (GPT-4.1-mini)
- Telegram API (Trigger y envío de mensajes)
- Agente AI para procesamiento de conversación

### Uso
1. Inicia una conversación con el bot en Telegram.
2. El asistente te saluda y pregunta por el tópico de libros que te interesa.
3. Recibe una lista de 10 libros recomendados con ranking basado en críticas.

## English

This n8n project is a conversational assistant that recommends books through Telegram using artificial intelligence. The workflow interacts with users to understand their literary interests and generates a ranking of the best books based on reviews.

### Main Features
- AI assistant specialized in book recommendations.
- Conversational interaction via Telegram.
- Generation of lists of 10 books with ranking based on reviews.
- Automatic and personalized response according to user interests.

### Tools and Nodes Used
- OpenAI (GPT-4.1-mini)
- Telegram API (Trigger and message sending)
- AI Agent for conversation processing

### Usage
1. Start a conversation with the bot on Telegram.
2. The assistant greets you and asks about the book topic that interests you.
3. Receive a list of 10 recommended books with ranking based on reviews.

Ideal for book lovers seeking personalized reading recommendations through an automated conversational interface.
